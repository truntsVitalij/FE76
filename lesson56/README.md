# Lesson 56 — Собеседования Junior (JS + React + TS, 2026)

Материал для занятия: как устроены собеседования на **junior frontend** в 2026 году, типичные вопросы и задачи — теория, React, TypeScript, алгоритмы.

## Файлы

| Файл | Для кого | О чём |
| ---- | -------- | ----- |
| [INTERVIEWQUESTIONS.md](./INTERVIEWQUESTIONS.md) | Студенты | Вопросы и задачи **без ответов** — для самопроверки и mock interview |
| [INTERVIEWANSWERS.md](./INTERVIEWANSWERS.md) | Преподаватель / после попытки | **Все ответы** с пояснениями и примерами кода |

## Как проводить занятие

1. Разберите раздел «Как проходит собеседование в 2026» из файла с вопросами.
2. Студенты отвечают вслух или письменно на блоки JS → TS → React → алгоритмы.
3. После каждого блока сверяют с `INTERVIEWANSWERS.md`.
4. На втором занятии — mock interview: 30 мин теория + 30 мин live coding (задачи §7–§8).
