styled-components - ещё один адекватный способ стилизации компонентов. Пока что используем только .module.css (никаких css)

Обязательный паттерн: ui-компоненты обязательно с className. Особенно, если нет ui-kit

API компонента - контракт с внешним миром. Строго задокументированный набор путей общения компонента с внешним миром и наоборот

stateless компоненты, глупые компоненты, ui-компоненты, ui-kit компоненты, презентационными компонентами - это компоненты, который НЕ СОДЕРЖАТ никакое состояние. Только вёрстка, стили и минимальная логика, если она нужна. Точка.

Жизненный цикл:
1 этап:
монтирование - первая отрисовка компонента в DOM

конструктор - создание экземпляра

2 этап:
компонент живёт жизнь и ожидает своего часа для перерисовки.
Причины перерисовок: 1. Изменение пропсов 2. Перерисовка родительского компонента
При перерисовке компонента он полностью перерисовывается, как и все его дочерние компоненты

3 этап:
Размонтирование
Полное его удаление из DOM

есть фуункциональный компонент и классовый
