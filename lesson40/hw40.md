1. Создать компонент layout (заметьте схожесть между разными страницами и зафиксируйте их в компоненте)
2. Необходимо создать три страницы
   2.1. Страница залогина (показываем её, когда в localstorage нет значение, указывающего на то, что вы ранее уже логировались)
   2.2. Страница blog, показывающая список карточек blog'a
   2.3. Страница successLogin, показывающая, что вы залогинились
3. Страница successLogin содержит кнопку, по клику на которую юзер перехоид на страницу блога
4. Страница blog:
   4.1. Открывается сразу же, если пользователь до этого залогинился
   4.2. Содержит табины, которые можно переключать
   4.3. Содержит список карточек blog'a
5. Страница залогина содержит форму, по которой юзер может залогиниться (email и passowrd в коде любой создайте)
