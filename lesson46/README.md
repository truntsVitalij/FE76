### Занятие

иммутабельность - данные неизменяемы во время работы с ними. Мы их создаём заново при необходимости.

### Критерии приёмки дипломных проектов

1. TS + React
2. SPA - single page application (мы подключаем React router)
3. React redux / toolkit / saga
4. Работа с API. То есть нужно найти free api на тему вашего диплома
5. Адекватный внешний вид (маломальский UI/UX)
6. Авторизация, если вам позволяет API сервера
7. Применение паттернов и подходов в написании кода, которые были изучены на занятиях

К концу этой недели необходимо предложить тему дипломного проекта и высокоуровнево оценить масштабы этого проекта.

Пример:

Тема: платформа прослушивания музыки.

1. Авторизация
2. Панель навигации со следующими пунктами (Альбомы, аудиокниги, Библиотека, Плейлисты)
3. Отображение списка альбомов, аудиокниг и т.д.
4. По клику на альбом, открывается страница со списком треков.
5. Каждый трек можно включить, послушать, лайкнуть
