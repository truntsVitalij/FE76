## На обсудить

1. Подход light frontend (лёгкий фронт) - фронт отвечает ТОЛЬКО за отрисовку, за подписку на пользовательские действия и отправку запросов на бекенд
2. Клиент-серверное приложение - любое web-приложение является клиент-серверным.
   Подразумевается что у нас есть часть клиента (front) и часть сервера (backend). Они общаются через сеть. ЧЕрез это общение (канал) обрабатываются любые запросы конечного пользователя.

   Front-часть - интерфейс, который видит конечный пользователь и с чем он взаимодействует (кликает на кнопки, скролит, вводит данные в инпуты и т.д.). Интерфейс - публичная (видимая) часть любого объекта
   Backend-часть - часть приложения, которая реагирует на те или иные запросы, приходящие с Front-части.

3. Верхнеуровневая архитектура - архитектура без деталей.
4. API (Application Programming Interface) - публичная, доступная часть чего-либо.
5. Mock - эмуляция, подделка, имитация

Клиент - юзер/пользователь
Фронт - front (ui-часть)
