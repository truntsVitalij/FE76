Почему React?

1. Популярность + кол-во вакансий. НО: не влияет на кол-во качественных спецов
2. К React больше верия из-за facebook.
3. REact простой для обучения. Низкий порог входа
4. Поддержка актуальной версии библиотеки.
5. Переход в мобильную разработку довольно прост (на react-native).
6. Декларативность ???
7. Virtual DOM - технология, позволяющая минимизировать кол-во реальных перерисовок в реальном DOM
8. JSX - синтаксис, который позволяет вставлять динамику в базовый HTML синтаксис тегов

Создаём react-app через vite. https://react.dev/learn/build-a-react-app-from-scratch#vite
